Japanese, from anime you already own.

Anime Mine plays video files on your Mac, lets you look up Japanese in the subtitles, and sends the words you want to keep into Anki.

Beta you build from source. A packaged app is ad-hoc signed. It is not notarized, and it is not an App Store build.

What it is

  1. 1

    Watch

    Point the library at a folder of video you already have. Subtitle files next to those videos are linked for you.

  2. 2

    Look up

    Click a word in the subtitles for the dictionary entry, furigana, and the sentence it came from.

  3. 3

    Mine

    Send the word, sentence, screenshot, and an audio clip to Anki through AnkiConnect.

First run

  1. Add a folder. Library, Add folder. Use files you own. Anime Mine does not download shows.
  2. Optional: Jimaku. Settings, Library. A free key from your jimaku.cc account fills in missing subtitles. Skip it when the files already have them.
  3. AnkiConnect. Install Anki and the AnkiConnect add-on (code 2055492159), then leave Anki open. The default address is http://127.0.0.1:8765.
  4. Optional: browser extension. Load the extension unpacked. In the app, Settings, Browser extension, copy the port and token. Extension README.

Build from source

Node.js 22.12 or newer, on macOS. Audio capture and the app bundle are Mac-only.

npm install
npm start
bash scripts/package-mac.sh

npm start runs the app in place. scripts/package-mac.sh writes ~/Applications/Anime Mine.app, sets the bundle version from package.json (0.1.0), keeps the id ai.animemine.app, and ad-hoc signs the bundle so the seal verifies. Gatekeeper still treats that build as unidentified. Developer ID signing and notarization are documented for when you have your own Apple certificate. They are not done for you, and there is no notarized binary on this site.
